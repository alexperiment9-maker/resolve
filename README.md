# Resolve

A planner that makes sure the plan gets done. Installable, works offline, no account, no AI. Your data stays on your device.

## Put it on GitHub Pages
1. github.com → New repository → name it `resolve` → Public → Create.
2. "uploading an existing file" → drop in every file from this folder → Commit changes.
3. Settings → Pages → Branch: `main`, folder `/ (root)` → Save.
4. Wait 1 to 2 minutes. Your app is at `https://YOUR-USERNAME.github.io/resolve/`.

## Install
Open the link in Chrome on your phone → menu → Add to Home screen (or Review → Install).

## Updating
Upload the new files, and change `VERSION` in `sw.js` (resolve-1 → resolve-2) so phones pick up the update.
